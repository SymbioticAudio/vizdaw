# VizDAW FFI and App Shell (Sub-project 2c) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove the whole stack end to end. A SwiftUI window opens a `.vizdaw` project, lists its sequences and lanes, and plays the selected sequence through the 2b engine. All state comes from Rust over UniFFI, and everything builds with the Command Line Tools only.

**Architecture:**
- `crates/core-ffi` (library `vizdaw_ffi`) exports a `Session` object (one per window) through UniFFI 0.32 proc-macros. The object wraps a 2a `History`, and `Session` methods return small snapshot records.
- A process-wide engine host owns the 2b `Engine`, which outputs either to the HAL (`platform-macos`) or to an `OfflineBackend` that a thread drives in real time (`VIZDAW_AUDIO=offline`). The `Engine` is `Send` but not `Sync`, so the host sits behind a `Mutex`. Only one session plays at a time, and device changes are handled the way `vizdaw-play`'s live loop handles them.
- `scripts/build-ffi.sh` builds the static library and generates Swift from the cdylib. A SwiftPM package (`app/`) links it through a C module target.
- View models (`VizDAWAppModel`) depend only on the generated `SessionProtocol`, so Swift Testing can drive them with a fake. The SwiftUI target is a thin view layer on top.

**Tech Stack:**
- Rust: stable (1.99.1 installed), edition 2024, `uniffi =0.32.2`, `thiserror 2`, and the path crates `core-model` (2a), `core-engine` with feature `fixtures`, and `platform-macos` (2b); dev dependency `tempfile 3`.
- Swift: 6.4 from the Command Line Tools, SwiftPM tools-version 6.0 with `--build-system native`, SwiftUI with the App lifecycle on macOS 14+, Observation, and Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-15-app-shell-design.md` is binding, and its Rulings are accepted.
- The 2b API is the real one in `crates/core-engine` and `crates/platform-macos` at `b32a88c`. It differs from the engine plan:
  - `Engine::new` returns `Result<(Engine, Renderer), EngineError>`;
  - `SinkFactory::make` takes an extra `target: TargetIdx`;
  - `InstrumentNode::skip` was added;
  - the engine chases and resets controllers internally;
  - the device-change rebuild lives in `crates/vizdaw-play/src/live.rs`.
- core-ffi uses `Engine`, `EngineConfig`, `OfflineBackend`, `OfflineSinks`, `EventLog`, `CoreAudioBackend`, `MacSinks` and `fixtures::demo_document`. It implements no `SinkFactory`, so the `make` change does not touch it.
- The 2a API is in `crates/core-model`.
- Executors read the spec, plus `live.rs` for Task 4.

## Review Focus

These are the five failure modes most likely to bite a user. The spec implies them but no spec test covers them. Each one is pinned by a named test in its owning task:

1. **Typing Space or Return while renaming a sequence.** The keys must type into the name field, not start playback or return to start, because the transport menu items have bare-key shortcuts.
   - Pinned: Task 6 `blankOrUnchangedRenameSendsNoCommand`, which asserts that `transportKeysEnabled` is false while renaming. Task 7 disables the menu items on that flag, and README step 5 covers it.
2. **Editing while playing.** Mute, undo and redo during playback must change what is heard within one block, without restarting or stopping playback.
   - Pinned: Task 4 `muting_while_playing_recompiles`, which reads the offline event log. It was proven able to fail when the recompile is removed.
3. **Two windows and a closing window.** Only one document sounds at a time. Closing or dropping the playing document silences it, and stopping one window never stops another.
   - Pinned: Task 4 `playing_a_second_session_stops_the_first` and `dropping_the_playing_session_stops_the_engine`.
4. **Opening something that is not a project.** This covers a plain folder, a `.vizdaw` folder without `project.json`, corrupt JSON and a newer format. Each gives a clear alert; none crashes.
   - Pinned: Task 2 `open_missing_path_is_not_found`, `open_corrupt_json_is_a_model_error` and `open_newer_format_names_the_version`; Task 6 `openRefusesFoldersWithoutTheExtension` and `openMissingProjectShowsTheError`.
5. **Saving where it cannot be saved, or saving an untitled document.** The result is an error alert (or a Save As panel). The document keeps its old path, and its dirty state stays truthful, including after an undo past the save.
   - Pinned: Task 2 `save_into_an_unwritable_place_is_an_io_error` and `save_while_untitled_is_an_io_error`; Task 3 `save_after_rename_writes_the_new_name_and_clears_dirty`; Task 6 `saveWhenUntitledNeedsSaveAs`.

## Plan Rulings

These are decisions the spec leaves open or that verification forced. Each is implemented and tested as stated. Format: Ruling — why — cost if wrong.

1. **Ruling:** `SeqRow.top_level` is `use_count == 0` (2a `query::usage::use_counts`) — why: the spec's sidebar split is "Top-level" vs "Used as reference", and the model has no top-level flag — cost if wrong: an unused scratch sequence shows as top-level. This is one line in `snapshot.rs`.
2. **Ruling:** `LaneRow.midi_event_count` counts every active-take event that is not a reference or an audio region, including text events — why: the table needs a cheap content count, not a playable count — cost if wrong: counts are slightly high on lanes with lyrics.
3. **Ruling:** `position_bbu` uses 2a `MeterMap::tick_to_bbu` with 960 units per beat, printed as `bar.beat.unit` (`5.2.480`; bar 0 is the pickup). `seconds` is the sequence tempo map's `tick_to_seconds` (negative in a pickup) — why: this matches the spec's example and keeps all formatting rules in Rust — cost if wrong: one constant (`UNITS_PER_BEAT`).
4. **Ruling:** `dirty` means the current document differs from the last opened or saved one. The comparison is structural; `im` maps short-circuit on shared nodes. Undoing back to the saved state is clean, and new and demo sessions start clean — why: this is what users expect from an Edited marker, and 2a's `History::execute` already compares documents this way — cost if wrong: a deep compare on huge edited projects. A version counter could replace it, local to `session.rs`.
5. **Ruling:** `DocSnapshot.version` increases on every successful command call, undo and redo, even a no-op command — why: it is a cheap "maybe changed" signal for lane refetches — cost if wrong: one extra `lanes` call after a no-op.
6. **Ruling:** `open` returns `NotFound` when the package directory or its `project.json` is missing, checked before loading. Other load failures map through `VizError::from(ModelError)` (`Io` → `Io`, everything else → `Model`) — why: the spec says "a missing package maps to NotFound", and 2a reports a missing file as `Io` — cost if wrong: none.
7. **Ruling:** `save_as` appends `.vizdaw` when it is missing and changes the session path only on success — why: the save panel may return a name without the extension — cost if wrong: none.
8. **Ruling:** feature `test-hooks` (enabled for tests through a self dev-dependency, as `core-engine` does with `fixtures`) adds `debug_panic`, `Session::debug_panic_locked`, `host::force_offline`, `host::reset_host` and `host::drain_offline_log` — why: Rust tests must select the offline backend without unsafe `set_var`, reset the process-wide host, and read the event log. Bindings come from a build without the feature, so Swift never sees these hooks — cost if wrong: none.
9. **Ruling:** the transport tests serialize on a static mutex, and each one forces offline mode and resets the host — why: the engine host is process-wide and cargo runs the tests of one binary in parallel — cost if wrong: none.
10. **Ruling:** the offline driver is a thread that renders the due frames every 2 ms at 48 kHz in 512-frame blocks, the same rate and block as 2b's offline renders — why: "OfflineBackend driven by a timer thread in real time" (spec §3) — cost if wrong: about 2 ms of jitter in offline positions, so tests compare ranges.
11. **Ruling:** Play resumes when the same session plays the same sequence again. Otherwise it reloads, starting from a position stored by `locate` while the session did not hold the engine (else bar 1). A session that does not hold the engine reports `playing: false` at that stored position — why: the spec defines "a play from another session stops the first one" but not the positions — cost if wrong: the first window's display jumps to its stored position after a takeover.
12. **Ruling:** fault names are sticky until the next Play. `report` holds the compile report's `warnings` followed by every `unroutable` reason — why: 2b's `Engine::faults()` reads and clears, while the UI polls at 33 ms — cost if wrong: none.
13. **Ruling:** device events are handled the way `vizdaw-play/src/live.rs` handles them, on the owner's next `transport()` poll:
    - A buffer-size change restarts the HAL output, after `Renderer::prepare` if the new buffer is larger.
    - A lost device, a new default device or a rate change rebuilds output and engine at the new device's rate (output dropped first), recompiles, locates to the old tick, and resumes if it was playing.
    - A still-alive device first gets 300 ms to play the note-offs; a lost one gets no wait.
    - A failed rebuild leaves no host: the transport reads stopped, and the next Play retries.
    - The test hooks `simulate_event` and `hosts_created` exercise this offline.

    Why: the coordinator asked core-ffi to mirror the CLI, and that keeps the position — cost if wrong: the UI thread blocks for up to 300 ms during a device switch, because the drain runs inside the poll.
14. **Ruling:** a recompile after an edit that deleted the loaded sequence stops playback and releases the engine. Dropping a `Session` also releases the engine — why: there would be nothing valid left to play, and a closed window must go silent — cost if wrong: none.
15. **Ruling:** the host's fields are ordered so the output stops (freeing the renderer) before the engine's collector thread is joined — why: no audio callback ever runs against a half-dropped engine — cost if wrong: none.
16. **Ruling:** `crates/core-ffi/src/lib.rs` sets `#![recursion_limit = "256"]` — why: UniFFI's `Send + Sync` check on `Session`, whose `History` holds `im` maps, overflows the default limit (verified: error E0275) — cost if wrong: none.
17. **Ruling:** `uniffi` is pinned `=0.32.2` with `default-features = false` in `core-ffi`; only `crates/uniffi-bindgen` enables `cli` — why: the generated scaffolding and bindgen must match exactly, and the runtime library does not need `cargo_metadata` — cost if wrong: none.
18. **Ruling:** `scripts/swift.sh` locates the Command Line Tools from `DEVELOPER_DIR` (default `/Library/Developer/CommandLineTools`), not from `xcode-select -p` — why: on this machine `xcode-select -p` points to the unlicensed `/Applications/Xcode.app`. With full Xcode working (`xcodebuild -version` succeeds), the script runs plain `swift` — cost if wrong: one line.
19. **Ruling:** view state such as the rename draft and the fault popover flag lives in `DocumentModel`, not in `@State` — why: on the CLT's default MacOSX27.0 SDK, `@State` is a macro whose `SwiftUIMacros` plugin is missing, and the build fails (verified) — cost if wrong: none. The state is testable there anyway.
20. **Ruling:** Swift shows `VizError.message` (an extension), not the generated `errorDescription` — why: UniFFI's `errorDescription` is `String(reflecting:)`, for example `VizError.Io(message: …)` — cost if wrong: none.
21. **Ruling:** `LaneRow`/`SeqRow` get `Identifiable` with a plain extension in `VizDAWAppModel`, not `@retroactive` — why: Swift 6.4 rejects `@retroactive` for types from the same package (verified) — cost if wrong: none.
22. **Ruling:** `DocumentStore` keeps a queue of documents without a window: Finder opens and launch arguments. The first window to appear adopts one, and the key window opens windows for the rest — why: `WindowGroup(for: UUID.self)` windows are opened from views, but Finder opens arrive in the app delegate — cost if wrong: a Finder open with every window closed waits until a window appears.
23. **Ruling:** launch arguments `--demo`, `path.vizdaw` and `--smoke`. `--smoke` plays the demo in the first window for 3 s, prints positions to stderr and exits 0 when the position advanced — why: automation here has no accessibility or screen-recording permission (verified), so the real window and poll loop are checked through the app itself — cost if wrong: one more code path in the app target.
24. **Ruling:** Open refuses, in Swift, any path whose extension is not `vizdaw`, with the alert "X is not a .vizdaw project." — why: spec ruling "validated by extension"; packages look like folders under `swift run` — cost if wrong: none.
25. **Ruling:** the transport menu's Space and Return items are disabled while a sequence name is being edited, and a blank or unchanged name sends no command — why: bare-key shortcuts would steal keystrokes from the text field (Review Focus 1) — cost if wrong: none.
26. **Ruling:** a failing `poll()` raises one alert and stays quiet until it is dismissed — why: polling runs 30 times a second — cost if wrong: none.
27. **Ruling:** the fault indicator is red when there are faults and orange when there are only compile messages, and it is hidden when both are empty — why: compile messages, such as unroutable events, are informational — cost if wrong: none.
28. **Ruling:** the File menu replaces SwiftUI's `.newItem` and `.saveItem` groups (New, Open…, Create Demo Project; Close, Save, Save As…), and `.undoRedo` is replaced by labelled Undo/Redo — why: the spec's menu list — cost if wrong: none.
29. **Ruling:** CI gets a separate `app` job on `macos-15` with full Xcode, where `swift.sh` uses the default build system. It runs `cargo test -p core-ffi`, `build-ffi.sh`, `swift.sh build/test` and `make-app.sh`, but not `--smoke` — why: tools-version 6.0 needs Xcode 16, and GUI launches on hosted runners are not reliable — cost if wrong: the window path is checked only locally (Task 7 step 5).
30. **Ruling:** the integration test waits 50 ms after Stop before it polls — why: the audio thread applies Stop on its next block, and `transport()` reads published atomics (observed: an immediate poll still reads playing) — cost if wrong: none.

```rust
use core_engine::{BackendError, EngineError};
use core_model::ModelError;
use vizdaw_ffi::{VizError, debug_panic, ffi_guard};

#[test]
fn model_errors_map_to_model_except_io() {
    let e: VizError = ModelError::invalid("nothing to undo").into();
    assert_eq!(
        e,
        VizError::Model {
            message: "invalid: nothing to undo".into()
        }
    );
    let e: VizError = ModelError::Io("disk full".into()).into();
    assert_eq!(
        e,
        VizError::Io {
            message: "disk full".into()
        }
    );
    let e: VizError = ModelError::NewerFormat { found: 99 }.into();
    assert!(matches!(e, VizError::Model { message } if message.contains("99")));
}

#[test]
fn engine_errors_map_to_engine_except_no_device() {
    let e: VizError = EngineError::Busy.into();
    assert!(matches!(e, VizError::Engine { .. }));
    let e: VizError = EngineError::Backend(BackendError::NoDevice).into();
    assert!(matches!(e, VizError::NoDevice { .. }));
    let e: VizError = BackendError::ComponentMissing.into();
    assert!(matches!(e, VizError::Engine { .. }));
}

#[test]
fn guard_passes_values_and_errors_through() {
    assert_eq!(ffi_guard(|| Ok(7)), Ok(7));
    let e = ffi_guard(|| -> Result<(), VizError> {
        Err(VizError::Io {
            message: "x".into(),
        })
    });
    assert_eq!(
        e,
        Err(VizError::Io {
            message: "x".into()
        })
    );
}

fn debug_panic_returns_internal_and_does_not_abort() {
    let e = debug_panic().unwrap_err();
    assert_eq!(
        e,
        VizError::Internal {
            message: "debug_panic called".into()
        }
```

```rust
//! `core-ffi` (library `vizdaw_ffi`): the UniFFI surface the SwiftUI app
//! uses. Rust owns all state; Swift gets snapshot records and calls
//! commands. No panic crosses the FFI: every export runs in [`ffi_guard`].
// `im` maps nest deeply; the `Send + Sync` check of `Session` needs more depth.
#![recursion_limit = "256"]
#![deny(missing_docs)]
#![cfg_attr(
    not(test),
    deny(
        clippy::unwrap_used,
        clippy::expect_used,
        clippy::indexing_slicing,
        clippy::panic
    )
)]

uniffi::setup_scaffolding!();

pub mod error;
pub mod guard;

pub use error::VizError;
pub use guard::ffi_guard;

/// Panics inside the guard (test hook): returns `VizError::Internal`.
#[cfg(feature = "test-hooks")]
#[uniffi::export]
pub fn debug_panic() -> Result<(), VizError> {
    ffi_guard(|| -> Result<(), VizError> {
        #[allow(clippy::panic)]
        {
            panic!("debug_panic called")
        }
    })
}
```

```rust
//! `VizError`, the one error type of the FFI (Swift: `throws VizError`).

use core_engine::{BackendError, EngineError};
use core_model::ModelError;

/// Every failure the app can see.
#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error, uniffi::Error)]
pub enum VizError {
    /// No project package (or no `project.json` in it) at `path`.
    #[error("no VizDAW project at {path}")]
    NotFound {
        /// The path that was tried.
        path: String,
    },
    /// The model refused a command or a file.
    #[error("{message}")]
    Model {
        /// Why.
        message: String,
    },
    /// A file-system failure.
    #[error("{message}")]
    Io {

        message: String,

    #[error("{message}")]
    NoDevice {
        /// Why.
        message: String,

    #[error("internal error: {message}")]
    Internal {
        /// The panic message.
        message: String,
    },
}

    fn from(e: ModelError) -> Self {
        match e {
            ModelError::Io(message) => VizError::Io { message },
            other => VizError::Model {
                message: other.to_string(),
            },
        }
    }
}

            BackendError::NoDevice => VizError::NoDevice {
                message: e.to_string(),
            },
            other => VizError::Engine {
                message: other.to_string(),
            },
        }
    }
}

    fn from(e: EngineError) -> Self {
        match e {
            EngineError::Backend(b) => b.into(),
            other => VizError::Engine {

            },
        }
    }
```

```rust
//! The panic guard and poison-tolerant locking.

use crate::error::VizError;
use std::any::Any;
use std::panic::{AssertUnwindSafe, catch_unwind};
use std::sync::{Mutex, MutexGuard, PoisonError};

/// Runs `f`, turning a panic into `VizError::Internal` (logged to stderr).
pub fn ffi_guard<T>(f: impl FnOnce() -> Result<T, VizError>) -> Result<T, VizError> {
    match catch_unwind(AssertUnwindSafe(f)) {
        Ok(r) => r,
        Err(payload) => {
            let message = panic_message(payload.as_ref());
            eprintln!("vizdaw-ffi: caught panic: {message}");
            Err(VizError::Internal { message })
        }
    }
}

/// The text of a panic payload.
pub fn panic_message(payload: &(dyn Any + Send)) -> String {
    if let Some(s) = payload.downcast_ref::<&str>() {
        (*s).to_string()
    } else if let Some(s) = payload.downcast_ref::<String>() {
        s.clone()
    } else {
        "unknown panic".to_string()
    }
}

/// Locks `m`, recovering a poisoned mutex (2a documents are replaced in
/// one assignment, so a panic never leaves a half-edited document).
pub fn lock<T>(m: &Mutex<T>) -> MutexGuard<'_, T> {
    m.lock().unwrap_or_else(PoisonError::into_inner)
}
```

```rust
/// Converts an FFI ID back to a sequence ID, rejecting unknown ones.

    let id = SeqId(seq);
    doc.sequence(id)?;

/// The sequence rows of `doc`.
pub fn seq_rows(doc: &Document) -> Result<Vec<SeqRow>, VizError> {
    let uses = use_counts(doc);
    doc.sequences()
        .values()
        .map(|s| {
            let use_count = uses.get(&s.id).copied().unwrap_or(0);
            Ok(SeqRow {
                id: s.id.0,
                name: s.name.clone(),
                use_count: count(use_count),
                top_level: use_count == 0,
                length_ticks: seq_length(doc, s.id)?.0,
                lane_count: count(s.lanes.len()),
                comment: s.comment.clone(),
            })
        })
        .collect()
}

/// The lane rows of sequence `seq`.
pub fn lane_rows(doc: &Document, seq: u64) -> Result<Vec<LaneRow>, VizError> {
    let s = doc.sequence(seq_id(doc, seq)?)?;
    Ok(s.lanes
        .iter()
        .map(|l| {
            let (mut midi, mut regions, mut refs) = (0usize, 0usize, 0usize);
            if let Some(take) = l.active() {
                for ev in take.events.values() {
                    match ev.body {
                        EventBody::Reference { .. } => refs += 1,
                        EventBody::AudioRegion { .. } => regions += 1,
                        _ => midi += 1,
                    }
                }
            }
            LaneRow {
                id: l.id.0,
                name: l.name.clone(),
                destination: l
                    .midi_dest
                    .and_then(|d| doc.instruments().get(&d).map(|d| d.name.clone())),
                midi_event_count: count(midi),
                region_count: count(regions),
                reference_count: count(refs),
                mute: l.mute,
                solo: l.solo,
                looped: l.looped,
                take_count: count(l.takes.len()),
                active_take: l.active().map(|t| t.name.clone()).unwrap_or_default(),
                is_drum: l.drum.is_some(),
            }
        })
        .collect())
}

/// Problems worth showing for `doc`.
pub fn warnings(doc: &Document) -> Vec<String> {
    let n = unresolved_events(doc).len();
    if n == 0 {
        Vec::new()
    } else {
        vec![format!("{n} reference(s) point to missing sequences")]
    }
}

/// `tick` in `seq` as "bar.beat.unit".
pub fn position_bbu(doc: &Document, seq: SeqId, tick: Tick) -> String {
    doc.sequence(seq).map_or_else(
        |_| String::new(),
        |s| {
            let p = s.meter.tick_to_bbu(tick, UNITS_PER_BEAT);
            format!("{}.{}.{}", p.bar, p.beat, p.unit)
        },
    )
}

/// `tick` in `seq` as seconds from bar 1, through the sequence's tempo map.
pub fn seconds(doc: &Document, seq: SeqId, tick: Tick) -> f64 {
    doc.sequence(seq)
        .map_or(0.0, |s| s.tempo.tick_to_seconds(tick))
}
```

```rust
use crate::guard::{ffi_guard, lock};

use core_model::document::Document;
use core_model::file;

use std::sync::{Arc, Mutex};

/// Package extension.

struct Inner {
    history: History,
    path: Option<PathBuf>,
    /// The document as last opened or saved; `dirty` compares against it.
    clean: Document,
    version: u64,
}

    fn new(doc: Document, path: Option<PathBuf>) -> Inner {
        Inner {
            history: History::new(doc.clone()),
            path,
            clean: doc,
            version: 0,
        }
    }

    fn doc(&self) -> &Document {
        self.history.doc()
    }

    fn snapshot(&self) -> Result<DocSnapshot, VizError> {
        let doc = self.doc();
        Ok(DocSnapshot {
            version: self.version,
            title: title(self.path.as_deref()),
            dirty: *doc != self.clean,
            undo_label: self.history.undo_label().map(str::to_string),
            redo_label: self.history.redo_label().map(str::to_string),
            sequences: seq_rows(doc)?,
            warnings: warnings(doc),
        })
```

```rust
/// Renders an offline backend in real time on its own thread.
struct OfflineDriver {
    stop: Arc<AtomicBool>,
    thread: Option<JoinHandle<()>>,
}

impl OfflineDriver {
    fn start(renderer: Renderer) -> Result<OfflineDriver, VizError> {
        let mut backend = OfflineBackend::new(OFFLINE_RATE, OFFLINE_BLOCK);
        backend.start(renderer)?;
        let stop = Arc::new(AtomicBool::new(false));
        let flag = Arc::clone(&stop);
        let thread = std::thread::Builder::new()
            .name("vizdaw-offline".into())
            .spawn(move || {
                let t0 = Instant::now();
                while !flag.load(Ordering::Relaxed) {
                    let due = (t0.elapsed().as_secs_f64() * OFFLINE_RATE) as u64;
                    if due > backend.frames() {
                        backend.run_frames(due - backend.frames());
                    }
                    std::thread::sleep(Duration::from_millis(2));
                }
                let _ = backend.stop();
            })
            .map_err(|e| VizError::Engine {
                message: format!("offline thread: {e}"),
            })?;
        Ok(OfflineDriver {
            stop,
            thread: Some(thread),
        })
    }
}

impl Drop for OfflineDriver {
    fn drop(&mut self) {
        self.stop.store(true, Ordering::Relaxed);
        if let Some(t) = self.thread.take() {
            let _ = t.join();
        }
    }
}

/// The engine and its output.
struct Host {

    // before the engine's collector thread is joined.
    output: Output,

    #[cfg_attr(not(feature = "test-hooks"), allow(dead_code))]

    injected: Vec<BackendEvent>,
}

impl Host {
    fn create() -> Result<Host, VizError> {
        HOSTS_CREATED.fetch_add(1, Ordering::Relaxed);
        if offline_mode() {
            let sinks = OfflineSinks::new(1 << 16);
            let log = sinks.log();
            let (engine, renderer) = Engine::new(EngineConfig::new(OFFLINE_RATE), Box::new(sinks))?;
            let output = Output::Offline(OfflineDriver::start(renderer)?);
            return Ok(Host::new(
                engine,
                output,
                OFFLINE_DEVICE,
                OFFLINE_RATE,
                Some(log),
            ));
        }
        Host::create_live()
    }

    #[cfg(target_os = "macos")]

        use platform_macos::hal::CoreAudioBackend;
        use platform_macos::sinks::MacSinks;
        let mut backend = CoreAudioBackend::new();
        let info = backend.open(&AudioConfig::default())?;
        let (engine, renderer) = Engine::new(
            EngineConfig::new(info.sample_rate),
            Box::new(MacSinks::new()),
        )?;
        backend.start(renderer)?;
        Ok(Host::new(
            engine,
            Output::Hal(backend),
            &info.device_name,
            info.sample_rate,
            None,
        ))
    }

    #[cfg(not(target_os = "macos"))]
    fn create_live() -> Result<Host, VizError> {
        Err(VizError::NoDevice {
            message: "live audio is macOS-only; set VIZDAW_AUDIO=offline".into(),

        output: Output,
        device: &str,
        sample_rate: f64,
        log: Option<EventLog>,

            output,
            engine,
            owner: 0,
            seq: SeqId(0),
            looped: false,
            device: device.to_string(),
            sample_rate,
            report: Vec::new(),
            faults: Vec::new(),
            log,
            injected: Vec::new(),
        }
    }

        let report = self.engine.load(doc, seq)?;
        self.report = report_lines(&report);
        self.engine.set_loop(looped)?;
        self.looped = looped;
        Ok(())
    }

    fn collect_faults(&mut self) {
        for name in self.engine.faults().names() {
            if !self.faults.iter().any(|f| f == name) {
                self.faults.push(name.to_string());
            }
        }
        let _ = self.engine.take_ended();
    }

    fn take_events(&mut self) -> Vec<BackendEvent> {
        let mut events = std::mem::take(&mut self.injected);
        match &mut self.output {
            Output::Offline(_) => {}
            #[cfg(target_os = "macos")]
            Output::Hal(b) => events.extend(b.take_events()),
        }
        events
    }

    /// Restarts the device with a larger buffer if needed (as the CLI does).
    fn restart_output(&mut self, frames: u32) -> Result<(), VizError> {
        match &mut self.output {
            Output::Offline(_) => Ok(()),

            Output::Hal(b) => {
                let mut r = b.stop()?;
                if frames > r.config().max_frames {

                }
                Ok(b.start(r)?)
            }
        }
    }

/// Handles device events for the owner (mirrors `vizdaw-play`'s live
/// loop): a buffer-size change restarts the output; a lost device, a new
/// default device or a rate change rebuild output and engine, recompile,
/// and resume at the same tick. A failed rebuild leaves no host.
fn handle_events(slot: &mut Option<Host>, doc: &Document) -> Result<(), VizError> {
    let Some(h) = slot.as_mut() else {
        return Ok(());
    };
    for ev in h.take_events() {
        match ev {
            BackendEvent::BufferSizeChanged(n) => {
                if let Some(h) = slot.as_mut() {
                    h.restart_output(n)?;
                }
            }
            BackendEvent::DeviceLost
            | BackendEvent::DefaultDeviceChanged
            | BackendEvent::SampleRateChanged(_) => {
                let Some(mut old) = slot.take() else {
                    return Ok(());
                };
                let at = old.engine.position_tick();
                let playing = old.engine.state() == PlayState::Playing;
                if !matches!(ev, BackendEvent::DeviceLost) {
                    // The device still renders: let the note-offs play.
                    let _ = old.engine.stop();
                    std::thread::sleep(DRAIN);
                }
                let (owner, seq, looped) = (old.owner, old.seq, old.looped);
                // Output first (frees the renderer), then the engine.
                drop(old);
                let mut new = Host::create()?;
                new.load(doc, seq, looped)?;
                new.engine.locate_tick(at)?;
                if playing {
                    new.engine.play()?;
                }
                new.owner = owner;
                new.seq = seq;
                *slot = Some(new);
                // The rebuilt host replaces any later queued events.
                return Ok(());
            }
        }
    }
    Ok(())
}

fn report_lines(r: &CompileReport) -> Vec<String> {
    let mut lines = r.warnings.clone();
    lines.extend(r.unroutable.iter().map(|u| u.reason.clone()));
    lines
}

/// Plays `seq` of `doc` for session `owner`. A different owner, sequence
/// or an explicit `start` reloads (stopping whoever played); otherwise the
/// engine resumes where it stopped.
pub fn play(
    owner: u64,
    doc: &Document,
    seq: SeqId,
    start: Option<Tick>,
    looped: bool,
) -> Result<(), VizError> {
    let mut slot = lock(&HOST);
    if slot.is_none() {
        *slot = Some(Host::create()?);
    }
    let host = slot.as_mut().ok_or_else(|| VizError::Internal {
        message: "engine host missing".into(),
    })?;
    if host.owner != owner || host.seq != seq || start.is_some() {
        host.engine.stop()?;
        host.load(doc, seq, looped)?;
        host.engine.locate_tick(start.unwrap_or(Tick::ZERO))?;
        host.owner = owner;
        host.seq = seq;
    }
    host.faults.clear();
    host.engine.play()?;
    Ok(())
}

/// Stops if `owner` is playing.
pub fn stop(owner: u64) -> Result<(), VizError> {
    let mut slot = lock(&HOST);
    match slot.as_mut() {
        Some(h) if h.owner == owner => Ok(h.engine.stop()?),
        _ => Ok(()),
    }
}

/// Moves `owner`'s transport. Returns false when `owner` does not hold
/// the engine (the caller keeps the position for its next Play).
pub fn locate(owner: u64, tick: Tick) -> Result<bool, VizError> {
    let mut slot = lock(&HOST);
    match slot.as_mut() {
        Some(h) if h.owner == owner => {
            h.engine.locate_tick(tick)?;
            Ok(true)
        }
        _ => Ok(false),
    }
}

/// Turns looping on or off if `owner` holds the engine.
pub fn set_loop(owner: u64, on: bool) -> Result<(), VizError> {
    let mut slot = lock(&HOST);
    match slot.as_mut() {
        Some(h) if h.owner == owner => {
            h.engine.set_loop(on)?;
            h.looped = on;
            Ok(())
        }
        _ => Ok(()),
    }
}

/// Recompiles after an edit if `owner` holds the engine.
pub fn reload(owner: u64, doc: &Document, looped: bool) -> Result<(), VizError> {
    let mut slot = lock(&HOST);
    match slot.as_mut() {
        Some(h) if h.owner == owner => {
            let seq = h.seq;
            // The loaded sequence may have been deleted by the edit.
            if doc.sequence(seq).is_err() {
                h.engine.stop()?;
                h.owner = 0;
                return Ok(());
            }
            h.load(doc, seq, looped)
        }
        _ => Ok(()),
    }
}

/// `owner`'s view of the transport, or `None` when it does not hold the
/// engine. For the owner, device events are handled first (`doc` is the
/// owner's document, needed to recompile after a rebuild).
pub fn state(owner: u64, doc: &Document) -> Result<Option<HostState>, VizError> {
    let mut slot = lock(&HOST);
    match slot.as_ref() {
        Some(h) if h.owner == owner => {}
        _ => return Ok(None),
    }
    handle_events(&mut slot, doc)?;
    let Some(h) = slot.as_mut() else {
        return Ok(None);
    };
    h.collect_faults();
    Ok(Some(HostState {
        playing: h.engine.state() != PlayState::Stopped,
        seq: h.seq,
        tick: h.engine.position_tick(),
        sample_rate: h.sample_rate,
        device: h.device.clone(),
        faults: h.faults.clone(),
        report: h.report.clone(),
    }))
}

/// Releases the engine if `owner` holds it (a session is closing).
pub fn release(owner: u64) {
    let mut slot = lock(&HOST);
    if let Some(h) = slot.as_mut() {
        if h.owner == owner {
            let _ = h.engine.stop();
            h.owner = 0;
        }
    }
}
```

```rust
static NEXT_ID: AtomicU64 = AtomicU64::new(1);

struct Inner {
    history: History,
    path: Option<PathBuf>,
    /// The document as last opened or saved; `dirty` compares against it.
    clean: Document,
    version: u64,
    looped: bool,
    /// Where the next Play starts when this session does not hold the
    /// engine; `None` means bar 1 (or resume when it does).
    cursor: Option<Tick>,
    /// The sequence `cursor` belongs to.
    cursor_seq: Option<SeqId>,
}

impl Inner {
    fn new(doc: Document, path: Option<PathBuf>) -> Inner {
        Inner {
            history: History::new(doc.clone()),
            path,
            clean: doc,
            version: 0,
            looped: false,
            cursor: None,
            cursor_seq: None,
        }
    }

    fn doc(&self) -> &Document {
        self.history.doc()
    }

    fn snapshot(&self) -> Result<DocSnapshot, VizError> {
        let doc = self.doc();
        Ok(DocSnapshot {
            version: self.version,
            title: title(self.path.as_deref()),
            dirty: *doc != self.clean,
            undo_label: self.history.undo_label().map(str::to_string),
            redo_label: self.history.redo_label().map(str::to_string),
            sequences: seq_rows(doc)?,
            warnings: warnings(doc),
        })
    }
}

/// "demo" for `/x/demo.vizdaw`, "Untitled" without a path.
fn title(path: Option<&Path>) -> String {
    path.and_then(Path::file_stem)
        .map(|s| s.to_string_lossy().into_owned())
        .unwrap_or_else(|| "Untitled".to_string())
}

/// Appends `.vizdaw` unless present.
fn with_extension(path: &str) -> PathBuf {
    let p = PathBuf::from(path);
    if p.extension().is_some_and(|e| e == EXTENSION) {
        p
    } else {
        let mut s = p.into_os_string();
        s.push(".");
        s.push(EXTENSION);
        PathBuf::from(s)
    }
}

/// One open document with its undo history and transport.
#[derive(uniffi::Object)]
pub struct Session {
    id: u64,
    inner: Mutex<Inner>,
}

impl std::fmt::Debug for Session {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        f.debug_struct("Session")
            .field("id", &self.id)
            .finish_non_exhaustive()
    }
}

impl Session {
    fn with(doc: Document, path: Option<PathBuf>) -> Arc<Session> {
        Arc::new(Session {
            id: NEXT_ID.fetch_add(1, Ordering::Relaxed),
            inner: Mutex::new(Inner::new(doc, path)),
        })
    }

    /// Applies one command as one undo step and recompiles if playing.
    fn execute(&self, cmd: Command) -> Result<DocSnapshot, VizError> {
        let mut inner = lock(&self.inner);
        inner.history.execute(&cmd, &ViewFilter::default())?;
        inner.version += 1;
        host::reload(self.id, inner.doc(), inner.looped)?;
        inner.snapshot()
    }

    /// Undo or redo, then recompile if playing.
    fn step(&self, undo: bool) -> Result<DocSnapshot, VizError> {
        let mut inner = lock(&self.inner);
        if undo {
            inner.history.undo()?;
        } else {
            inner.history.redo()?;
        }
        inner.version += 1;
        host::reload(self.id, inner.doc(), inner.looped)?;
        inner.snapshot()
    }

    /// Runs a transport call; an `Internal` error drops the engine host so
    /// the next Play starts clean.
    fn transport_call<T>(&self, f: impl FnOnce() -> Result<T, VizError>) -> Result<T, VizError> {
        let r = ffi_guard(f);
        if let Err(VizError::Internal { .. }) = &r {
            host::reset();
        }
        r
    }
}

#[uniffi::export]
impl Session {
    /// An untitled, empty document.
    #[uniffi::constructor]
    pub fn new_empty() -> Result<Arc<Session>, VizError> {
        ffi_guard(|| Ok(Session::with(Document::new(), None)))
    }

    /// An untitled copy of the demo project.
    #[uniffi::constructor]
    pub fn new_demo() -> Result<Arc<Session>, VizError> {
        ffi_guard(|| {
            let doc = core_engine::fixtures::demo_document()?;
            Ok(Session::with(doc, None))
        })
    }

    /// Opens the `.vizdaw` package at `path`.
    #[uniffi::constructor]
    pub fn open(path: String) -> Result<Arc<Session>, VizError> {
        ffi_guard(|| {
            let p = PathBuf::from(&path);
            if !p.join(file::PROJECT_FILE).is_file() {
                return Err(VizError::NotFound { path });
            }
            let doc = file::load(&p)?;
            Ok(Session::with(doc, Some(p)))
        })
    }

    /// Saves to the current path; `Io` when untitled.
    pub fn save(&self) -> Result<(), VizError> {
        ffi_guard(|| {
            let mut inner = lock(&self.inner);
            let path = inner.path.clone().ok_or_else(|| VizError::Io {
                message: "the document has no file yet; use Save As".into(),
            })?;
            file::save(inner.doc(), &path)?;
            inner.clean = inner.doc().clone();
            Ok(())
        })
    }

    /// Saves to `path` (`.vizdaw` appended if missing) and makes it the
    /// current path.
    pub fn save_as(&self, path: String) -> Result<(), VizError> {
        ffi_guard(|| {
            let mut inner = lock(&self.inner);
            let p = with_extension(&path);
            file::save(inner.doc(), &p)?;
            inner.clean = inner.doc().clone();
            inner.path = Some(p);
            Ok(())
        })
    }

    /// The current package path.
    pub fn path(&self) -> Result<Option<String>, VizError> {
        ffi_guard(|| {
            let inner = lock(&self.inner);
            Ok(inner
                .path
                .as_ref()
                .map(|p| p.to_string_lossy().into_owned()))
        })
    }

    /// The document at sequence level.
    pub fn snapshot(&self) -> Result<DocSnapshot, VizError> {
        ffi_guard(|| lock(&self.inner).snapshot())
    }

    /// The lanes of sequence `seq`.
    pub fn lanes(&self, seq: u64) -> Result<Vec<LaneRow>, VizError> {
        ffi_guard(|| lane_rows(lock(&self.inner).doc(), seq))
    }

    /// Renames sequence `seq` (one undo step).
    pub fn rename_sequence(&self, seq: u64, name: String) -> Result<DocSnapshot, VizError> {
        ffi_guard(|| {
            self.execute(Command::Sequence(SequenceCmd::Rename {
                seq: SeqId(seq),
                name,
            }))
        })
    }

    /// Mutes or unmutes lane `lane` of sequence `seq` (one undo step).
    pub fn set_lane_mute(&self, seq: u64, lane: u64, mute: bool) -> Result<DocSnapshot, VizError> {
        ffi_guard(|| {
            self.execute(Command::Lane(LaneCmd::SetFlags {
                seq: SeqId(seq),
                lane: LaneId(lane),
                mute: Some(mute),
                solo: None,
                arm: None,
            }))
        })
    }

    /// Reverts the last step.
    pub fn undo(&self) -> Result<DocSnapshot, VizError> {
        ffi_guard(|| self.step(true))
    }

    /// Reapplies the last undone step.
    pub fn redo(&self) -> Result<DocSnapshot, VizError> {
        ffi_guard(|| self.step(false))
    }

    /// Plays sequence `seq`, stopping any other session. Resumes where
    /// this session stopped when the same sequence is still loaded.
    pub fn play(&self, seq: u64) -> Result<(), VizError> {
        self.transport_call(|| {
            let mut inner = lock(&self.inner);
            let id = seq_id(inner.doc(), seq)?;
            // A position set while another session held the engine.
            let start = match (inner.cursor, inner.cursor_seq) {
                (Some(t), None) => Some(t),
                (Some(t), Some(s)) if s == id => Some(t),
                _ => None,
            };
            host::play(self.id, inner.doc(), id, start, inner.looped)?;
            inner.cursor = None;
            inner.cursor_seq = Some(id);
            Ok(())
        })
    }

    /// Stops; the position is kept.
    pub fn stop(&self) -> Result<(), VizError> {
        self.transport_call(|| host::stop(self.id))
    }

    /// Moves the position to `tick`.
    pub fn locate(&self, tick: i64) -> Result<(), VizError> {
        self.transport_call(|| {
            let mut inner = lock(&self.inner);
            if !host::locate(self.id, Tick(tick))? {
                inner.cursor = Some(Tick(tick));
            }
            Ok(())
        })
    }

    /// Loops from bar 1 to the end of the sequence, or stops looping.
    pub fn set_loop(&self, on: bool) -> Result<(), VizError> {
        self.transport_call(|| {
            let mut inner = lock(&self.inner);
            inner.looped = on;
            host::set_loop(self.id, on)
        })
    }

    /// Where the transport stands.
    pub fn transport(&self) -> Result<TransportState, VizError> {
        self.transport_call(|| {
            let inner = lock(&self.inner);
            let doc = inner.doc();
            Ok(match host::state(self.id, doc)? {
                Some(h) => TransportState {
                    playing: h.playing,
                    seq: Some(h.seq.0),
                    tick: h.tick.0,
                    position_bbu: position_bbu(doc, h.seq, h.tick),
                    seconds: seconds(doc, h.seq, h.tick),
                    sample_rate: h.sample_rate,
                    device: h.device,
                    faults: h.faults,
                    report: h.report,
                },
                None => {
                    let tick = inner.cursor.unwrap_or(Tick::ZERO);
                    let seq = inner.cursor_seq;
                    TransportState {
                        playing: false,
                        seq: seq.map(|s| s.0),
                        tick: tick.0,
                        position_bbu: seq
                            .map_or_else(|| "1.1.0".to_string(), |s| position_bbu(doc, s, tick)),
                        seconds: seq.map_or(0.0, |s| seconds(doc, s, tick)),
                        sample_rate: 0.0,
                        device: String::new(),
                        faults: Vec::new(),
                        report: Vec::new(),
                    }
                }
            })
        })
    }
}
```

```swift
import Foundation
import VizDAWCore

/// Pure display helpers.
public enum Formatting {
    /// `m:ss.fff`, with a leading `-` before zero (pickups).
    /// Non-finite input gives `--:--.---`.
    public static func time(_ seconds: Double) -> String {
        guard seconds.isFinite else { return "--:--.---" }
        let totalMs = Int64((abs(seconds) * 1000).rounded())
        let sign = seconds < 0 && totalMs > 0 ? "-" : ""
        let minutes = totalMs / 60_000
        let secs = (totalMs / 1000) % 60
        let ms = totalMs % 1000
        return sign + String(format: "%d:%02d.%03d", minutes, secs, ms)
    }

    /// Bar·beat·unit as Rust formats it (`5.2.480`, `0.4.0` in a pickup,
    /// `-1.1.0` before it); empty input shows `-.-.-`.
    public static func bbu(_ position: String) -> String {
        position.isEmpty ? "-.-.-" : position
    }

    /// Toolbar position: `bbu  m:ss.fff`.
    public static func position(_ t: TransportState) -> String {
        "\(bbu(t.positionBbu))  \(time(t.seconds))"
    }

    /// `48 kHz`, `44.1 kHz`; empty for 0.
    public static func sampleRate(_ hz: Double) -> String {
        guard hz > 0, hz.isFinite else { return "" }
        let k = hz / 1000
        let text = k.rounded() == k ? String(format: "%.0f", k) : String(format: "%.1f", k)
        return "\(text) kHz"
    }

    /// `Device · 48 kHz`, or `No output` before the first Play.
    public static func device(_ t: TransportState) -> String {
        t.device.isEmpty ? "No output" : "\(t.device) · \(sampleRate(t.sampleRate))"
    }

    /// The window title: `title`, plus ` — Edited` when dirty.
    public static func windowTitle(_ s: DocSnapshot) -> String {
        s.dirty ? "\(s.title) — Edited" : s.title
    }
}
```

```swift
/// An error shown to the user.
public struct AlertItem: Identifiable, Equatable, Sendable {
    public let id = UUID()
    public let title: String
    public let message: String

    public init(title: String, message: String) {
        self.title = title
        self.message = message
    }

    /// An alert for any thrown error; `VizError`s show their message.
    public init(_ error: any Error, title: String) {
        self.title = title
        if let e = error as? VizError {
            message = e.message
        } else {
            message = error.localizedDescription
        }
    }

    public static func == (a: AlertItem, b: AlertItem) -> Bool {
        a.title == b.title && a.message == b.message
    }
}

    /// The human-readable text of the error.

        case let .NotFound(path): "No VizDAW project at \(path)."
        case let .Model(message): message
        case let .Io(message): message
        case let .Engine(message): message
        case let .NoDevice(message): "No audio output: \(message)"
```

```swift
import Foundation
import Observation
import VizDAWCore

/// One window's document: snapshot, selection, lanes and transport.
/// All state comes from the session; intents call it and refresh.
@Observable
@MainActor
public final class DocumentModel {
    public let session: any SessionProtocol
    public private(set) var snapshot: DocSnapshot
    public private(set) var selectedSeq: UInt64?
    public private(set) var lanes: [LaneRow] = []
    public private(set) var transport: TransportState
    public private(set) var looping = false
    /// The sequence whose name is being edited in the sidebar.
    public private(set) var renamingSeq: UInt64?
    /// The edited name (view state lives here: the Command Line Tools
    /// cannot expand SwiftUI's `@State` macro).
    public var renameDraft = ""
    /// The fault popover is open.
    public var showsFaults = false
    public var alert: AlertItem?
    /// Version and selection the current `lanes` were fetched for.
    private var lanesKey: LanesKey?
    /// How often `lanes` were fetched (tests check refetch rules).
    public private(set) var laneFetches = 0

    private struct LanesKey: Equatable {
        let version: UInt64
        let seq: UInt64?
    }

    public init(session: any SessionProtocol) throws {
        self.session = session
        snapshot = try session.snapshot()
        transport = try session.transport()
        apply(snapshot)
    }

    // MARK: Derived state

    public var topLevel: [SeqRow] { snapshot.sequences.filter(\.topLevel) }
    public var referenced: [SeqRow] { snapshot.sequences.filter { !$0.topLevel } }
    public var windowTitle: String { Formatting.windowTitle(snapshot) }
    public var undoTitle: String { snapshot.undoLabel.map { "Undo \($0)" } ?? "Undo" }
    public var redoTitle: String { snapshot.redoLabel.map { "Redo \($0)" } ?? "Redo" }
    public var canUndo: Bool { snapshot.undoLabel != nil }
    public var canRedo: Bool { snapshot.redoLabel != nil }
    public var isPlaying: Bool { transport.playing }
    /// Transport keys (Space, Return) are off while a name is edited, so
    /// typing a space types a space.
    public var transportKeysEnabled: Bool { renamingSeq == nil }
    public var canPlay: Bool { selectedSeq != nil || isPlaying }
    /// 33 ms while playing, 250 ms when stopped (to catch the end).
    public var pollInterval: Duration { isPlaying ? .milliseconds(33) : .milliseconds(250) }
    public var hasFaults: Bool { !transport.faults.isEmpty }
    public var hasReport: Bool { !transport.report.isEmpty }
    public var selectedName: String? {
        snapshot.sequences.first { $0.id == selectedSeq }?.name
    }

    // MARK: Intents

    public func select(_ seq: UInt64?) {
        guard seq != selectedSeq else { return }
        selectedSeq = seq
        refreshLanes()
    }

    public func beginRename(_ seq: UInt64) {
        renameDraft = snapshot.sequences.first { $0.id == seq }?.name ?? ""
        renamingSeq = seq
    }

    public func cancelRename() { renamingSeq = nil }

    /// Renames the sequence being edited; a blank or unchanged name
    /// just ends editing.
    public func commitRename(_ name: String) {
        guard let seq = renamingSeq else { return }
        renamingSeq = nil
        let trimmed = name.trimmingCharacters(in: .whitespacesAndNewlines)
        let current = snapshot.sequences.first { $0.id == seq }?.name
        guard !trimmed.isEmpty, trimmed != current else { return }
        rename(seq, to: trimmed)
    }

    public func rename(_ seq: UInt64, to name: String) {
        command("Rename Failed") { try $0.renameSequence(seq: seq, name: name) }
    }

    public func setMute(lane: UInt64, _ mute: Bool) {
        guard let seq = selectedSeq else { return }
        command("Mute Failed") { try $0.setLaneMute(seq: seq, lane: lane, mute: mute) }
    }

    public func toggleMute(lane: UInt64) {
        guard let row = lanes.first(where: { $0.id == lane }) else { return }
        setMute(lane: lane, !row.mute)
    }

    public func undo() { command("Undo Failed") { try $0.undo() } }

    public func redo() { command("Redo Failed") { try $0.redo() } }

    public func playStop() {
        do {
            if isPlaying {
                try session.stop()
            } else if let seq = selectedSeq {
                try session.play(seq: seq)
            }
        } catch {
            alert = AlertItem(error, title: isPlaying ? "Stop Failed" : "Play Failed")
        }
        poll()
    }

    public func toggleLoop() {
        do {
            try session.setLoop(on: !looping)
            looping.toggle()
        } catch {
            alert = AlertItem(error, title: "Loop Failed")
        }
    }

    public func returnToStart() {
        do {
            try session.locate(tick: 0)
        } catch {
            alert = AlertItem(error, title: "Locate Failed")
        }
        poll()
    }

    /// Reads the transport. A failure shows one alert, not one per poll.
    public func poll() {
        do {
            transport = try session.transport()
        } catch {
            if alert == nil { alert = AlertItem(error, title: "Transport Failed") }
        }
    }

    /// True when Save needs a path first (untitled).
    public var needsSaveAs: Bool { ((try? session.path()) ?? nil) == nil }

    public func save() {
        perform("Save Failed") { try $0.save() }
    }

    public func saveAs(path: String) {
        perform("Save Failed") { try $0.saveAs(path: path) }
    }

    // MARK: Plumbing

    private func command(_ title: String, _ body: (any SessionProtocol) throws -> DocSnapshot) {
        do {
            apply(try body(session))
        } catch {
            alert = AlertItem(error, title: title)
        }
    }

    private func perform(_ title: String, _ body: (any SessionProtocol) throws -> Void) {
        do {
            try body(session)
            apply(try session.snapshot())
        } catch {
            alert = AlertItem(error, title: title)
        }
    }

    /// Takes a new snapshot: keeps the selection if the sequence still
    /// exists (else the first top-level one), refetches lanes if needed.
    func apply(_ s: DocSnapshot) {
        snapshot = s
        if selectedSeq.map({ id in !s.sequences.contains { $0.id == id } }) ?? true {
            selectedSeq = s.sequences.first(where: \.topLevel)?.id ?? s.sequences.first?.id
        }
        if let r = renamingSeq, !s.sequences.contains(where: { $0.id == r }) {
            renamingSeq = nil
        }
        refreshLanes()
    }

    private func refreshLanes() {
        let key = LanesKey(version: snapshot.version, seq: selectedSeq)
        guard key != lanesKey else { return }
        lanesKey = key
        guard let seq = selectedSeq else {
            lanes = []
            return
        }
        do {
            laneFetches += 1
            lanes = try session.lanes(seq: seq)
        } catch {
            lanes = []
            alert = AlertItem(error, title: "Lanes Unavailable")
        }
    }
}
```

```swift
/// The open documents, one per window, keyed by the window's value.
@Observable
@MainActor
public final class DocumentStore {
    public typealias Make = () throws -> any SessionProtocol
    public typealias Open = (String) throws -> any SessionProtocol

    public private(set) var documents: [UUID: DocumentModel] = [:]
    /// Documents created without a window yet (Finder opens, launch
    /// arguments); the next window to appear adopts the first one.
    public private(set) var pending: [UUID] = []
    /// Failures that have no window to show them in.
    public var alert: AlertItem?

    private let makeEmpty: Make
    private let makeDemo: Make
    private let openPath: Open

    public init(makeEmpty: @escaping Make, makeDemo: @escaping Make, open: @escaping Open) {
        self.makeEmpty = makeEmpty
        self.makeDemo = makeDemo
        self.openPath = open
    }

    /// The store backed by the Rust library.
    public static func live() -> DocumentStore {
        DocumentStore(
            makeEmpty: { try Session.newEmpty() },
            makeDemo: { try Session.newDemo() },
            open: { try Session.open(path: $0) }
        )
    }

    public func model(_ id: UUID) -> DocumentModel? { documents[id] }

    public func newEmpty() -> UUID? { add("New Document Failed", makeEmpty) }

    public func newDemo() -> UUID? { add("Demo Project Failed", makeDemo) }

    /// Opens a `.vizdaw` package; other paths are refused with an alert.
    public func open(path: String) -> UUID? {
        guard (path as NSString).pathExtension == "vizdaw" else {
            alert = AlertItem(
                title: "Open Failed",
                message: "\((path as NSString).lastPathComponent) is not a .vizdaw project.")
            return nil
        }
        return add("Open Failed") { try self.openPath(path) }
    }

    /// Queues a document for the next window to appear.
    public func enqueue(_ id: UUID?) {
        if let id { pending.append(id) }
    }

    /// The oldest queued document, removed from the queue.
    public func takePending() -> UUID? {
        pending.isEmpty ? nil : pending.removeFirst()
    }

    public func close(_ id: UUID) {
        if let doc = documents.removeValue(forKey: id), doc.isPlaying {
            try? doc.session.stop()
        }
    }

    private func add(_ title: String, _ make: Make) -> UUID? {
        do {
            let model = try DocumentModel(session: make())
            let id = UUID()
            documents[id] = model
            return id
        } catch {
            alert = AlertItem(error, title: title)
            return nil
        }
    }
}
```

```swift
/// `VizDAW [--demo] [--smoke] [path.vizdaw ...]`: documents for the first
/// windows. `--smoke` (implies `--demo`) plays the first window for 3 s,
/// prints the transport and exits 0 if the position advanced, else 1.
enum LaunchArguments {
    @MainActor static var smoke = false

    @MainActor static func apply(_ args: [String], to store: DocumentStore) {
        for arg in args.dropFirst() {
            if arg == "--smoke" {
                smoke = true
                store.enqueue(store.newDemo())
            } else if arg == "--demo" {
                store.enqueue(store.newDemo())
            } else if arg.hasSuffix(".vizdaw") {
                store.enqueue(store.open(path: arg))
            }
        }
    }
}

/// The `--smoke` run: Play, poll for 3 s through the window's model, exit.
enum SmokeRun {
    @MainActor static func start(_ model: DocumentModel) {
        guard LaunchArguments.smoke else { return }
        LaunchArguments.smoke = false
        Task { @MainActor in
            try? await Task.sleep(for: .milliseconds(300))
            model.playStop()
            var ticks: [Int64] = []
            for _ in 0..<12 {
                try? await Task.sleep(for: .milliseconds(250))
                model.poll()
                ticks.append(model.transport.tick)
                FileHandle.standardError.write(Data(
                    "smoke: \(model.selectedName ?? "-") \(Formatting.position(model.transport)) playing=\(model.isPlaying) device=\(Formatting.device(model.transport))\n".utf8))
            }
            let ok = model.alert == nil && (ticks.last ?? 0) > (ticks.first ?? 0)
            if let a = model.alert {
                FileHandle.standardError.write(Data("smoke: alert \(a.title): \(a.message)\n".utf8))
            }
            FileHandle.standardError.write(Data("smoke: \(ok ? "ok" : "FAILED")\n".utf8))
            exit(ok ? 0 : 1)
        }
    }
}
```

```swift
import SwiftUI
import VizDAWAppModel

/// One window: adopts a queued document or makes an empty one, shows it,
/// polls the transport while key and opens windows other code requested.
struct DocumentWindow: View {
    @Binding var id: UUID?
    let store: DocumentStore
    @Environment(\.openWindow) private var openWindow
    @Environment(\.controlActiveState) private var activeState

    var body: some View {
        Group {
            if let id, let model = store.model(id) {
                DocumentView(model: model)
                    .focusedSceneValue(\.documentModel, model)
                    .task(id: PollKey(key: activeState == .key, playing: model.isPlaying)) {
                        guard activeState == .key else { return }
                        while !Task.isCancelled {
                            model.poll()
                            try? await Task.sleep(for: model.pollInterval)
                        }
                    }
                    .onAppear { SmokeRun.start(model) }
                    .onDisappear { store.close(id) }
            } else {
                ProgressView()
            }
        }
        .onAppear {
            if id == nil {
                id = store.takePending() ?? store.newEmpty()
            }
            openQueued()
        }
        .onChange(of: store.pending) { openQueued() }
        .alert(
            store.alert?.title ?? "",
            isPresented: Binding(
                get: { store.alert != nil && activeState == .key },
                set: { if !$0 { store.alert = nil } }),
            presenting: store.alert
        ) { _ in
            Button("OK") { store.alert = nil }
        } message: { item in
            Text(item.message)
        }
    }

    /// Opens a window for every queued document (only the key window
    /// does it, so each opens once).
    private func openQueued() {
        guard activeState == .key || store.documents.count <= 1 else { return }
        while let next = store.takePending() {
            openWindow(value: next)
        }
    }
}

private struct PollKey: Equatable {
    let key: Bool
    let playing: Bool
}
```

```bash
#!/usr/bin/env bash
# Builds dist/VizDAW.app (release, ad-hoc signed). No Xcode needed.
set -euo pipefail
root="$(cd "$(dirname "$0")/.." && pwd)"
cd "$root"

scripts/build-ffi.sh
scripts/swift.sh build -c release --product VizDAW
bin="$(scripts/swift.sh build -c release --product VizDAW --show-bin-path 2>/dev/null | tail -1)"

app="dist/VizDAW.app"
rm -rf "$app"
mkdir -p "$app/Contents/MacOS" "$app/Contents/Resources"
cp "$bin/VizDAW" "$app/Contents/MacOS/VizDAW"
cat > "$app/Contents/Info.plist" <<'PLIST'

<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">

    <key>CFBundleExecutable</key><string>VizDAW</string>
    <key>CFBundlePackageType</key><string>APPL</string>
    <key>CFBundleShortVersionString</key><string>0.1.0</string>
    <key>CFBundleVersion</key><string>1</string>
    <key>CFBundleInfoDictionaryVersion</key><string>6.0</string>
```

- [ ] **Step 3: Write the README**

Create `app/README.md`:

````markdown
# VizDAW app (SwiftUI shell)

A minimal macOS 14+ app over the Rust core (`crates/core-ffi`, UniFFI).
It builds with the Command Line Tools alone; no Xcode project.

## Build and run

```bash
scripts/build-ffi.sh              # Rust static library + generated Swift bindings
scripts/swift.sh run VizDAW       # opens a window (add --demo to start with the demo)
scripts/swift.sh test             # Swift Testing suite (needs build-ffi.sh first)
scripts/make-app.sh               # dist/VizDAW.app, ad-hoc signed
```

`scripts/swift.sh` adds `--build-system native` and the Swift Testing
framework paths that the Command Line Tools need. With full Xcode installed
it runs plain `swift`.

Launch arguments: `--demo` opens the demo project; a path ending in
`.vizdaw` opens that project; `--smoke` plays the demo for 3 s, prints the
transport and exits 0 when the position advanced.

`VIZDAW_AUDIO=offline` renders through the offline backend in real time
(no sound, device label "Offline"). Never set it for normal use.

Generated files (not in git): `app/Sources/VizDAWCore/vizdaw_ffi.swift`,
`app/Sources/vizdaw_ffiFFI/include/`, `target/ffi/`, `dist/`.

## Manual smoke test

1. `scripts/build-ffi.sh && scripts/swift.sh run VizDAW`. A window appears
   in front with a menu bar (File, Edit, Transport).
2. File > Create Demo Project. A second window opens; the sidebar shows
   Song under "Top-level" and Beat (1) and Groove (2) under "Used as
   reference".
3. Song is selected; the table lists the lanes Groove and Chords. Press
   Space: the demo sounds through the speakers, the position display
   advances (bar.beat.unit and m:ss.fff), the tempo slows over the last two
   bars, and playback stops by itself at the end.
4. Press Space again and, while it plays, switch Mute on for Chords: the
   chords drop out within a moment. Edit > Undo Set Lane Mute/Solo/Arm
   brings them back.
5. Double-click Beat in the sidebar, type `Kit`, press Return; the title
   gains " — Edited". Typing a space in the name field types a space and
   does not start playback.
6. File > Save As… `~/Desktop/demo.vizdaw`, close the window (Cmd-W),
   File > Open… and choose `~/Desktop/demo.vizdaw`: the sequence is still
   called Kit. Choosing a folder without `.vizdaw` shows an alert.
7. Unplug or switch the output device during playback: playback stops and
   the next Play uses the new device.
8. `scripts/make-app.sh`, then `open dist/VizDAW.app`; double-click
   `~/Desktop/demo.vizdaw` in Finder: it opens in VizDAW.
````
